Why

Every project I had built sat on top of something that had already decided what a frame was. I wanted to write that part myself, once, so I would know what it costs.

How

The snake body is a queue. Push a head, pop a tail — movement stops being a loop over segments and becomes a data structure choice. The terminal is the framebuffer.

It played perfectly until I got good at it. Then the snake started eating itself through corners it had already left.

The bug

Collision detection ran after the render. The check was comparing against the frame on screen, not the state in memory. At slow speed the stale frame lives 80 milliseconds and nobody notices. At speed, it is the difference between alive and dead.

// the entire fix
  read_input();
  advance();
- render();
- check_collisions();   // asks the screen
+ check_collisions();   // asks the truth
+ render();

Now

Clean at every speed I can play. No dependencies means it compiles to WebAssembly, so the browser version is the same source — not a rewrite that drifts.
